## Общее описание решения

CppTemplates — учебный плагин для CLion, который вставляет шаблоны функции `main`, цикла `for` и класса в текущую позицию курсора. Команды доступны в меню **Tools** и через двухэтапные горячие клавиши. Вставку можно отменить через **Ctrl+Z**.

Плагин написан на Java с использованием IntelliJ Platform API. Среда разработки — IntelliJ IDEA; проверенная целевая среда — CLion 2026.2.2 под Windows 11 25H2. Для сборки используется JDK 21 и Gradle Wrapper проекта.

## Структура проекта

- `src/main/java/ru/student/cpptemplates/InsertMainAction.java` — вставка функции main.
- `src/main/java/ru/student/cpptemplates/InsertForAction.java` — вставка цикла for с сохранением отступа строки.
- `src/main/java/ru/student/cpptemplates/InsertClassAction.java` — вставка класса.
- `src/main/resources/META-INF/plugin.xml` — описание плагина, зависимости, регистрация команд и горячих клавиш.
- `build.gradle.kts` — зависимости и целевая платформа CLion.
- `settings.gradle.kts` — версии плагинов сборки и репозитории зависимостей.
- `gradle.properties` — группа проекта, версия и параметры Gradle.
- `gradlew`, `gradlew.bat`, `gradle/wrapper/` — Gradle Wrapper.

## Описание команд с примерами использования

### InsertMainAction

**Назначение:** вставляет заготовку программы. Курсор устанавливается на пустой строке внутри `main` после четырёх пробелов.

**Пример:** откройте пустой файл `main.cpp` и выберите **Tools → Insert C++ Main**.

```cpp
#include <iostream>

int main() {
    
    return 0;
}
```

### InsertForAction

**Назначение:** вставляет цикл со счётчиком от 0 до 9. Сохраняет пробельный отступ перед курсором и добавляет четыре пробела для тела цикла. Курсор устанавливается внутри тела.

**Пример:** после вставки `main` вызовите **Tools → Insert C++ For Loop**, не перемещая курсор.

```cpp
int main() {
    for (int i = 0; i < 10; ++i) {
        
    }
    return 0;
}
```

### InsertClassAction

**Назначение:** вставляет класс `MyClass` с конструктором по умолчанию, методами `setValue` и `getValue`, закрытым полем `value_`. Курсор устанавливается перед именем класса.

**Пример:** поставьте курсор на пустую строку после `#include`, перед `main`, и выберите **Tools → Insert C++ Class**.

```cpp
class MyClass {
public:
    MyClass() = default;

    void setValue(int value) {
        value_ = value;
    }

    int getValue() const {
        return value_;
    }

private:
    int value_ = 0;
};
```

## Описание методов классов действий

### actionPerformed(AnActionEvent event)

**Параметр:** `event` — событие вызова команды, из которого получаются текущий проект и редактор.  
**Возвращаемое значение:** отсутствует (`void`).  
**Действие:** проверяет доступность проекта, редактора и записи в документ; вставляет шаблон через `WriteCommandAction`; перемещает курсор. Изменение документа оформляется как отменяемая команда.

### update(AnActionEvent event)

**Параметр:** `event` — контекст обновления команды.  
**Возвращаемое значение:** отсутствует (`void`).  
**Действие:** включает команду при наличии проекта и редактора с доступным для записи документом; иначе отключает её.

### getActionUpdateThread()

**Параметры:** отсутствуют.  
**Возвращаемое значение:** `ActionUpdateThread.BGT`.  
**Назначение:** указывает фоновый поток для обновления доступности команды. Саму вставку выполняет `actionPerformed` в команде изменения документа.

## Горячие клавиши

| Команда | Первый шаг | Второй шаг |
|---|---|---|
| Insert C++ Main | Ctrl+Alt+Shift+T | M |
| Insert C++ For Loop | Ctrl+Alt+Shift+T | F |
| Insert C++ Class | Ctrl+Alt+Shift+T | C |

Нажмите первое сочетание, отпустите все клавиши и нажмите вторую букву без модификаторов. Сочетания проверялись в английской раскладке. При конфликтах настройте их через **Settings → Keymap**. Регистрация в `plugin.xml` использует keymap `$default`.

## Архитектура подключения к IDE

CLion основан на IntelliJ Platform. Плагин использует общие API редактора и систему действий платформы. В `plugin.xml` объявлены зависимости `com.intellij.modules.platform` и `com.intellij.clion`. В разделе `actions` классы наследников `AnAction` связаны с пунктами группы `ToolsMenu` и сочетаниями клавиш.

При вызове команды IDE передаёт `AnActionEvent`. Через него плагин получает `Project` и `Editor`, затем `Document` и положение курсора. `WriteCommandAction` организует изменение документа и поддержку отмены. Плагин вставляет обычный текст и не использует синтаксический анализ C++.

## Сборка и запуск

Откройте проект в IntelliJ IDEA, выберите JDK 21 для Gradle и дождитесь синхронизации. Команды ниже выполняются в PowerShell из корня проекта:

```powershell
.\gradlew.bat compileJava
.\gradlew.bat runIde
.\gradlew.bat buildPlugin
```

`compileJava` компилирует Java-код; `runIde` запускает отдельный тестовый CLion; `buildPlugin` создаёт ZIP в `build/distributions`. Перед повторным запуском закройте предыдущий тестовый экземпляр IDE.

## Установка

1. Соберите плагин командой `buildPlugin`.
2. В CLion откройте **Settings → Plugins → ⚙ → Install Plugin from Disk…**.
3. Выберите ZIP из `build/distributions`, не распаковывая его.
4. При необходимости перезапустите CLion.
5. Откройте исходный файл и проверьте команды в меню **Tools**.

## Проверка работоспособности

- Проверены вставка каждого из трёх шаблонов и двухэтапные горячие клавиши.
- Проверены положение курсора в `main` и `for`, сохранение отступов цикла и отмена вставки.
- Выполнены сборка ZIP и установка в обычный CLion.
- После изменения исходников необходимо повторно собрать и установить ZIP.

## Ограничения

- Шаблоны вставляются в позицию курсора; выделенный текст не заменяется.
- Команды доступны для любого открытого записываемого текстового документа: расширение файла не проверяется.
- Плагин не проверяет наличие `main`, `#include` или класса с таким же именем.
- Для правильного отступа цикла вызывайте команду на пустой строке после отступа. Вложенный уровень добавляет четыре пробела независимо от настроек форматирования IDE.
- При переименовании `MyClass` измените также имя конструктора.
